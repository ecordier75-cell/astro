# Correction du calcul lunaire — 23 novembre 2026

Remplacement de la formule lunaire simplifiée par les termes principaux de longitude géocentrique de la table 47.A de Jean Meeus, *Astronomical Algorithms*, avec correction de l’excentricité et trois termes additionnels. Calcul entièrement hors connexion.

Comparaison Swiss Ephemeris (mode Moshier, utilisé seulement pour les tests) :
- Série originale : 192 instants UTC, écart maximal 0,01564939°, écart moyen 0,00649315°, 0 au-dessus de 0,1°.
- Série indépendante : 192 instants UTC, écart maximal 0,01684974°, écart moyen 0,00869896°, 0 au-dessus de 0,1°.

La version précédente présentait des écarts maximaux respectifs de 0,12837° et 0,12293°. Ces résultats ne certifient pas la précision universelle, ni les autres planètes, maisons, dates extrêmes ou fuseaux. La conversion UTC→TT reste approximative. Aucun APK n’a été compilé.
