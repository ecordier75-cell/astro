# Projet de politique de confidentialité — à adapter et publier

Les Astres d’Éric, dans la version hors ligne fournie, traite localement les informations saisies (prénom, date, heure, lieu, latitude, longitude, décalage UTC) pour générer un thème astrologique. L'application ne demande aucune permission réseau, ne crée aucun compte et n'intègre pas de publicité ni de traceur analytique. Elle ne transmet pas les données à un serveur. L'impression PDF est déclenchée volontairement par l'utilisateur via le système Android ; le document peut alors être enregistré ou transmis selon le service choisi.
