# Audit de précision — Pluton

27 comparaisons (9 années × 3 villes), calculées à 12 h UTC.

- Erreur angulaire maximale : **0.02035°**.
- Erreur angulaire moyenne : **0.01135°**.
- Référence : Swiss Ephemeris, calcul Moshier via `pyswisseph`, non intégré à l'application.

Ces tests ne valident pas les fuseaux historiques ni les positions pour toutes les dates. Les autres planètes et les maisons nécessitent toujours une validation complète.

**Aucune compilation APK/AAB ni signature n'a été réalisée.**
